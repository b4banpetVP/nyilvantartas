# Nyilvantartas :3

Kedves teammatem az Erikecske :3

A legpremiumabb servicet nyujtjuk!!!

Programunk szamon fogja tartani a teruletre erkezo jarmuvek es emberek leirasat.

Eloszor a program kiirja az erkezes pontos idopontjat.

Ezutan bekeri, hogy szemely vagy auto erkezett.

Az 1-es menuponttal megtudja adni, hogy szemely erkezett.
Az 2-es menuponttal megtudja adni, hogy auto erkezett.

Amennyiben szemely erkezett: keri a szemely nevet es a szemelyi azonosito szamat.
Amennyiben auto erkezett: az auto tipusat es rendszamat.
